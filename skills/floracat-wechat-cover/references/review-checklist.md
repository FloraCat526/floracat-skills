# 双封面验收

先检查单图，再看组合图。视觉检查需要实际打开图片；脚本与文件检查不能证明图中语义正确。

## 人物与风格

- [ ] 与图一/图二是同一小沅 IP，脸型、蓝发、眼睛与服装正确；动作合理，手指/道具没有明显畸形。
- [ ] 两图主题、人物和配色一致；蓝紫保持明亮通透，浅黄保持奶油白与暖色点缀。
- [ ] 没有误植示例标题、无关品牌、二维码或水印。

## 内容

- [ ] 标题、专名、中文、标点逐字核对，没有漏字、错字或多余文字。
- [ ] 场景表达文章核心行为，不凭示意界面编造数据或产品能力。
- [ ] 标题化封面保持用户观点，强调词不夸大原意。
- [ ] 架构图式保留真实节点、分组、方向和循环；简化内容在 brief 有记录，箭头不穿越文字或人物。

## 布局与缩略

- [ ] 大图横版、小图方形；小图独立重排，不能只是大图缩小/硬裁。
- [ ] 字体、人物和关键图形有安全边距；主次清晰，不依赖放大才能理解。
- [ ] 小图约 160×160 显示仍能认出人物、主题和关键道具/核心结构。
- [ ] 组合图左大右小、等高无缝，左右没有跨缝元素、变形或意外遮挡。
- [ ] 三个 PNG 能正常打开，实际尺寸与 layout.json 一致。补边自然，裁切有明确授权和复查。

## 完成记录

把通过的检查与未解决问题写入 brief。尚有错字、人物漂移、技术关系错误时继续修正；生成能力缺失时准确报告缺口，不把 prompt 或占位输出作为最终封面。
