# Skill 生命周期

## 1. 草稿期

先在 `drafts/` 中整理：
- 目标场景
- 典型输入
- 输出形式
- 工作流
- 可复用资源

## 2. 定型期

当 skill 已经可以重复使用时，迁入 `skills/`：
- 补齐 `SKILL.md`
- 抽出 `references/`、`scripts/`、`assets/`
- 明确命名和适用范围

## 3. 复用期

持续根据实际使用修改：
- 增强触发描述
- 缩短无效说明
- 增加 review checklist
- 沉淀共用模板到 `shared/`

## 4. 发布期（未来可选）

如果未来要做公开仓库或市场发布，再补：
- 截图
- 发布脚本
- marketplace 元数据
- changelog
- CI
